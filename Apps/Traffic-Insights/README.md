# Rain & Traffic Insights app

Start the existing unified server from the repository root:

```bash
python Apps/main.py
```

Open `http://localhost:8080/insights`. The app is mounted by `Apps/main.py`; `GET /api/insights` returns preaggregated chart data as JSON. It reads the committed `DataAnalysis/output/*.csv` tables and uses only Python's standard library for its own backend. The existing server requirements still apply.

If the computer does not have the computer-vision and lakehouse dependencies needed by the other apps, run `python Apps/main.py --insights-only`. This still opens the dashboard at `/insights` through `main.py`, without starting the other routes.

The new exploratory split is generated by:

```bash
python -m DataAnalysis.rain.stratified
```

It writes `stratified_effects.csv` and `rain_timing.csv` into `DataAnalysis/output/`. The first table compares rainy camera-hours against each camera's dry baseline for the same hour and day type. The second shows when rainy hours occurred, by hour of day and weekday/weekend type.

**New data-quality insight:** the apparent weekday/weekend contrast is driven in part by *when* rain occurred. The 69 rainy weekday camera-hours are concentrated at 16:00 and 18:00–20:00; the 224 rainy weekend camera-hours are concentrated at 13:00–17:00. Only 16:00 and 17:00 appear in both groups, and weekday 17:00 has just one rainy camera-hour. Pooled motorcycle effects are −34.3% on weekdays versus −13.9% on weekends, but at the shared 16:00 hour they are −26.8% and −32.4% respectively (two weekday clock hours, one weekend clock hour). The pooled subgroup gap is therefore **not a reliable day-type effect**. This finding warns against an attractive but misleading conclusion and identifies the need for more weekday and weekend rain events at comparable hours.

Light (1–<5 mm) and heavier (≥5 mm) rain have similar pooled motorcycle effects (−20.6% and −21.6%). The heavier group contains just five distinct clock hours, and the two intensity groups also differ in timing; there is no clear dose-response conclusion.

The dashboard keeps the existing main analysis's caveats: still images cannot measure speed, traffic flow, ride-hailing prices, or transit passengers. Flood sensors in this dataset lack coordinates, so their readings cannot be matched directly to a camera.
